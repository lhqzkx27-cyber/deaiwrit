# 去 AI 味写作 De-AI Writ（deaiwrit）

> 让 AI 生成或改写的中文文字，去掉那股"AI 味"——整齐、空洞、说教、套话、无主体的腔调，变得像**有观点、有细节、有边界的人**写的。

一个面向**任何 LLM agent / 任何使用者**的「检测 + 改写」中文去 AI 味 skill。核心是一款**确定性打分器** `detect_ai.py`：它不靠"感觉"，而是把 AI 味的可观测特征（词汇套话 + 句式结构）量化成得分，给出 `clean / mild / ai` 三级判定，并列出命中了哪些信号、改了哪些该改。

---

## 它解决什么问题

现在大模型写出来的中文，往往一眼能看出"是 AI 写的"：

- 句句都是规整长句，句长几乎一模一样（**机械均匀**）
- 满屏"综上所述 / 具有重要意义 / 让我们共同努力 / 随着…的发展"
- 空洞总结式结尾，翻来覆去把前面的话又说一遍
- 用"很多人 / 大家 / 我们每个人"替代具体的人，用"很多 / 一些 / 长期"替代具体数字
- 观点四平八稳，和稀泥，不碰反例

对学生（课程论文、综测、推免材料）、写作者、做内容审核和评测的人，这套东西能：

1. **检测**：一段文字是多像 AI 写的，量给你看
2. **改写**：按文体（散文/议论文/说明文/小说/学术/新媒体/网文）给出不被 AI 味污染的改法
3. **自查**：生成完过一遍清单，堵住 AI 腔

---

## 亮点（与"感觉派"提示词的区别）

| | 感觉派 / 通用提示词 | **本 skill（deaiwrit）** |
|---|---|---|
| 判定依据 | "感觉像不像" | 可复现的**量化打分**（三层信号加权） |
| 文体 | 一刀切"改得更抒情" | **分 7 类文体**各按本色改写，学术里正当的"众所周知"不误伤 |
| 句式 | 不看 | **句长/段落变异系数**抓"机械均匀"，纯词法漏掉的机械 AI 也抓得到 |
| 结果 | 改没改好?难说 | 返回得分、分级、命中清单、是否规整文体 |

**三层检测信号**
- **词法层（抓套话）**：揭题词 ×2、解释性动词 ×0.5、模糊词 ×0.3，学术文体自动降权
- **结构层（抓机械句）**：句长变异系数 CV、段落变异系数——AI 机械文本句长均匀（CV≈0.17），人类叙述参差（CV≈0.6）；CV 极低可判 ai
- **门槛保护**：仅靠弱信号不判 ai；诗词/典籍等规整文体自动豁免结构信号，不误伤真实诗词

## 快速开始

需要 Python 3.8+（纯标准库，无任何第三方依赖）。

```bash
git clone git@github.com:lhqzkx27-cyber/deaiwrit.git
cd deaiwrit

# 检测一段文本
python assets/run_detect.py --text "这段文字..."

# 检测一个文件
python assets/run_detect.py --file 某文件.txt

# 批量检测一个目录 → 导出 CSV
python assets/run_detect.py --dir 某目录 --out report.csv
```

输出示例：

```
ai  score=33.0  hits=['综上所述', '极大']     # AI 味重，需要重写
clean  score=0.0  hits=[]                     # 基本干净
```

- **score < 1.0 → clean**（干净）
- **1.0 ≤ score < 3.0 → mild**（有 AI 味，局部改）
- **score ≥ 3.0 → ai**（AI 味重，大改/重写）

## 作为 Agent Skill 使用

`SKILL.md` 是给任何 LLM agent 读的完整使用说明（frontmatter 里带 `name` 和 `description`），放进 agent 的 skill 目录即可被自动发现。它包含：

- 三种工作模式：**改写 / 生成 / 检测**
- 7 类文体（A 抒情散文 / B 议论文 / C 说明文 / D 记叙小说 / E 学术论文 / F 新媒体 / G 网文）各自的**本色改写规则**
- 写后**自查清单**与"人味注入"清单

让 agent 做的事极简单：读 `SKILL.md`，跑 `run_detect.py` 拿打分，按文体规则改，过自查清单。

## 验证与测试

基于**真实人类语料约 40 万篇**（维基百科 + 诗词古籍 + 现代诗 + 散文 + 学术）和 **875 篇 AI 样本**自测迭代（详见 `self_test_report.md`）：

- 真实百科误报率 **~0.3%**；多文体（含诗词）误报率 **~1.2%**
- AI 样本 **100% 检出**
- 纯机械 AI（词法干净、句法均匀）也能靠结构信号判 ai——这是纯词法检测器做不到的

## 使用示例

**检测**："我这段是不是像 AI 写的？"
```bash
python assets/run_detect.py --text "首先，随着社会的不断发展，人工智能在我们的日常生活中扮演着越来越重要的角色。综上……"
# → ai  score=33.0  hits=['综上所述', '极大']
```

**改写**："把这段散文改得更像人写的。" → 读 `SKILL.md` 的 A 类（抒情散文）规则：找具体物/场景闭环、删情绪词改用动作暗示、视角锁死"我"、结尾停画面上不总结。

**生成**："写一篇议论文。" → 起手避开揭题词，观点推到可被质疑的判断，直面反例，结尾斩钉截铁，过自查清单。
